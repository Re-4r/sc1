# تعليمات الاستكمال لمطور آخر / Claude Code

أنت تتولى تطوير منصة «مساحة» التعليمية. افتح `README.md` و`docs/PRODUCT_SPEC.md` و`docs/TEST_REPORT.md` أولًا. لا تستبدل التصميم الحالي بتصميم بطاقات مربعة مكرر، ولا تستخدم أي رمز نجمة. احتفظ بالهوية الحالية الباردة والهادئة للمعلمة، وبهوية السبورة الطفولية الناعمة المنفصلة عبر `projector.html`. راعِ أن المستخدم يريد جميع الصفحات مرتبة وقابلة للتحكم وخط PingARLT.

## نقطة الاستلام

المشروع الحالي HTML/CSS/JS وPWA ابتدائي، يعمل محليًا عبر localStorage، وواجهة الأدوار مجرد معاينة وليست مصادقة. هناك اختبارات متصفح أساسية ناجحة، لكن لا يوجد خادم حقيقي أو حماية حسابات ولا رفع ملفات كبير. لا تصف المشروع بأنه جاهز للنشر المدرسي.

## التنفيذ المرحلي الآمن

1. استخرج منطق البيانات من `assets/app.js` إلى طبقة خدمات API، ثم ابنِ خادم PHP 8.1+ أو تقنية موثوقة مع قاعدة بيانات، وملف إعدادات سري خارج الجذر العام، واختبارات صلاحيات لكل دور.
2. وفّر تسجيل دخول آمنًا للمعلمة والطالبة وولي الأمر والإدارة، مع الفصل التام لبيانات الطالبات، وآلية دعوات وموافقة/تحقق لولي الأمر. يمنع اعتماد الاسم أو رقم الجوال دون تحقق.
3. نفّذ تخزين ملفات كبير resumable/object storage مع قيود الصلاحيات، PDF/PPT/video وجدولة الوصول وتوثيق المدخلات والنسخ الاحتياطي.
4. اجعل شاشة السبورة مصادقًا على جلستها بمدة محددة، والاتصال الحي عبر WebSocket/SSE دون كشف معلومات الإدارة.
5. أكمل تسلسل الدروس والكتاب ودفتر الطالبة واختبارات الرياضيات والتصحيح المعنوي للكسور والصور والمهارات وأرقام الصفحات والتحقق قبل النشر.
6. أكمل الألعاب متعددة الفرق والمجموعات، ووحدة الجداول والمقاعد، تقارير المهارات والعلاج، الشهادات، إسناد الدروس للصفوف والتذكيرات.
7. اختبر كل قسم على Safari iOS وChrome Android وWindows/Mac/iPad، وراجع أداء 1000+ مستخدم وصلاحيات API.

## تعليمات عند قرب انتهاء حد الجلسة

- احفظ آخر نسخة فعلية تعمل في ZIP مع الملفات كاملة، وليس ملفات Diff فقط.
- أنشئ `HANDOFF_STATUS.md`: ما نُفّذ بالضبط، وما اختُبر ونتيجته، والأخطاء المعروفة، والفجوات المتبقية، القرارات المتخذة، والملفات التي تعدلت، وآخر إصدار وcommit إن وجد.
- أنشئ `NEXT_SESSION_PROMPT.md` موجّهًا لحساب جديد، يشرح نقطة الاستئناف والخطوة الأولى والبيئة والأوامر، بدون اختراع نجاحات.
- سلّم صور معاينة منفصلة للمعلمة والطالبة والسبورة والهواتف، مع التنويه إن لم تكن اختُبرت فعليًا.
- لا تضغط تغييرات ضخمة في الدقيقة الأخيرة؛ سلّم نسخة مستقرة واكتب ما بقي.
