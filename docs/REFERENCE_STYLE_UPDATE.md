# مساحة — تحديث الهوية البصرية استنادًا إلى math.zip

هذه **نسخة كاملة من مشروع المعاينة السابق** وليست مشروعًا جديدًا. تم الحفاظ على `index.html` و`projector.html` و`skills.html` وجميع ملفات JavaScript والوظائف. أُضيف ملفان للتصميم فقط:

- `assets/reference-refresh.css`: للوحة المعلمة والسبورة، مع تعزيز حالات التفاعل والتجاوب.
- `assets/skills-ref.css`: لمختبر مهارات الرياضيات وتجربة الطالبة.

## ما اقتبسناه من مرجع المستخدم
الخلفية `#F6F5FB` والأسطح البيضاء `#FFFFFF` والكتابة `#242D48` والأزرار الكحلية الهادئة `#4C5D90`، وحواف `#E4E1F1` ولمسات الألوان الزرقاء والموف والنعناعية الخافتة. لم تُنقل قواعد البيانات أو ملفات الخادم من `math.zip` إلى هذا النموذج، ولم تُغيّر صلاحياته.

## طريقة الفتح
افتح `index.html` من داخل المجلد بعد فك الضغط. تشغيل خادم محلي أو استضافة HTTPS أفضل لتزامن نافذة البروجكتر وميزات PWA. يمكن فتح `skills.html` منفصلًا لمعاينة المختبر، و`projector.html` للسبورة.

## حدود هذا التحديث
هذه **ترقية تصميم** وليست تحويلًا إلى الخادم PHP داخل المرجع. تظل قيود الحسابات الحقيقية وحماية بيانات الطالبات والرفع الكبير والمزامنة متعددة الأجهزة كما هي في وثائق النسخة السابقة. لا تستخدم بيانات طالبات حقيقية قبل تنفيذ ذلك وتدقيقه.
