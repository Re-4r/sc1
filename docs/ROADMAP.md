# سجل متطلبات المشروع وخارطة الإنجاز

## ما أصبح في معاينة قابلة للتفاعل

- الرئيسية: ترحيب المعلمة، التاريخ، العد التنازلي للحصة حسب الجدول، المهام اليومية والروتين، التنبيهات والإعدادات.
- قائمة مختصرة والتنقل لمركز الدروس، والتقويم أيقونة فقط في الشريط العلوي.
- مساحة الدرس: فكرة الدرس، الأهداف، المعرفة السابقة، التهيئة، الاستراتيجيات، الوسائل، التقييم، العلاج والإثراء، القيم، الواجب.
- تسلسل مشاهد الحصة: الترحيب، قواعد الصف، المراجعة، الأهداف، الشرح، النشاط، التقييم وغيرها، مع إضافة وتعديل وتقديم وتأخير وحذف وعرض مستقل للطالبات.
- مكتبة محلية ذات معاينة محدودة للكتب PDF والفيديو والصور. لا خادم لرفع ملفات المدرسة.
- النافذة المستقلة للسبورة، التعتيم، سؤال وحل، مؤقت، ولوحة خاصة للمعلمة.
- أقسام تجريبية للطالبات، أولياء الأمور، الواجبات، المهارات، الفصول، الحضور، التقارير والألعاب.

## مطلوب قبل اعتماد النظام للاستخدام المدرسي الحقيقي

**الأولوية الأولى:** حسابات آمنة منفصلة حسب الدور، عزل البيانات لكل مدرسة وفصل وطالبة، تحكم خادمي بالصلاحيات، تدقيق وتشفير نسخ احتياطي؛ قاعدة بيانات وتخزين وسائط يمكن زيادته والتحكم بالوصول إليه، دعم رفع ملفات كبيرة برفع مجزأ، إدارة الكتب والعروض وتصفح الصفحات.

**المرحلة التالية:** نظام تحضير مُهيكل وفق القالب المدرسي المعتمد، ربط الدرس بصفحات الكتاب، إظهار صورة صفحة الكتاب/الفيديو/العرض على البروجكتر حسب موضع المشهد، منظّم تفاعلي لسحب وترتيب المشاهد، دفتر الطالبة الإلكتروني، الكسور الرياضية المتكافئة، تصحيح الإجابات متعدد الأشكال، الألعاب المحسوبة والتقييم والمجموعات وخطة علاجية.

**بعدها:** دعوات أولياء الأمور ذات صلاحيات قابلة للتخصيص لكل فصل؛ شهادات PDF؛ ملف إنجاز المعلمة؛ التقارير؛ استيراد Excel/JSON مع مراجعة؛ موجهات AI قابلة للنسخ؛ إحصاءات؛ اختبارات تلقائية؛ سجلات النظام؛ PWA كاملة متعددة الأجهزة.

## ملاحظة أمنية وتشغيلية

«رفع ZIP وفك ضغطه فقط» يحقق تشغيل **واجهة استعراضية** على استضافة ثابتة. لا يمكن أن يجعل وحده نظامًا بآلاف الفيديوهات وحسابات طالبات آمنًا؛ ذلك يحتاج إعدادًا للخادم، تخزينًا، نسخًا احتياطيًا، وصلاحيات. أي ادعاء بخلاف ذلك غير صحيح.

## الاختبارات

تم التحقق آليًا من صياغة JavaScript (`node --check`) ومن وجود الملفات والمراجع وسلامة ZIP؛ لم ينجح فتح Chromium في بيئة التنفيذ (حظر إداري)، ولذلك لا يُدّعى نجاح اختبار بصري شامل أو جميع مسارات التفاعل.
