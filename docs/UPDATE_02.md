# تحديث مساحة 02 — مختبر المهارات

## المنفّذ

1. إضافة مركز مهارات من داخل قائمة المعلمة، واستدعاؤه من واجهة الطالبة التجريبية.
2. إدارة بنك الأسئلة: إضافة، تعديل، حذف، تصنيف حسب الصف والمهارة.
3. دعم ثلاث صيغ: إجابة عددية، كسور متكافئة، اختيار متعدد.
4. تصحيح حسابي محلي يقبل الأرقام العربية والهندية والإنجليزية، ويفحص تساوي الكسر/العدد العشري باستخدام مقادير نسبية مبسطة بدل مقارنة النصوص.
5. تدريب طفولي هادئ مع زر «ما فهمت»، تلميحات اختيارية وتغذية راجعة ونتيجة نهاية التدريب.
6. سجل محاولات محلي ومحدود، واستيراد وتصدير JSON مع فحص مدخلات.
7. تحديث ملف ذاكرة PWA إلى الإصدار الثاني ليشمل الملفات الجديدة.

## ما زال مطلوبًا قبل الإنتاج

- نظام هوية وحسابات للمعلمة والطالبة وولي الأمر، وتحديد صلاحيات الوصول على الخادم.
- قاعدة بيانات خادم ونتائج معتمدة غير قابلة لتعديل الطالبة.
- مراجعة بنك الأسئلة مع الكتاب الرسمي والتوثيق برقم الصفحة، قبل استخدامه في التقييم.
- محرك تعلم رياضي أوسع للتعابير المركبة والوحدات والهندسة والكسور المختلطة.
- رفع مقاطع وعروض كبيرة لخادم وتخزين مخصص؛ واجهة المكتبة الحالية تجريبية.
- اختبارات واجهة شاملة على Safari وChrome وEdge وFirefox قبل النشر.

## نتيجة الفحص

- `node --check assets/app.js`: اجتاز فحص الصياغة.
- `node --check assets/skills.js`: اجتاز فحص الصياغة.
- مراجعة بنية المشروع وروابط الملفات محليًا.
- تعذر إجراء اختبار متصفح آلي كامل في بيئة التنفيذ بسبب رفض التنقل إلى الصفحات المحلية؛ لا ندعي نجاح الاختبارات المرئية.

## قواعد التطوير

- لا تعرض لوحة تحكم المعلمة في `projector.html` أبدًا.
- لا تستخدم نجمة في أدوات الحصة أو في هوية المشروع.
- الواجهات التجريبية لا تُستخدم مع بيانات الطالبات الحقيقية.
