# تقرير الاختبار — مساحة

## المنفذ

- التحقق من سلامة بناء JavaScript باستخدام `node --check` لكلا ملفي `app.js` و`projector.js`.
- اختبار واجهة المعلمة داخل Chromium عبر Playwright باستخدام تحميل HTML/CSS/JS داخل صفحة مع ذاكرة محلية افتراضية للتغلب على تقييد فتح localhost في بيئة الاختبار.
- ظهرت الصفحة الرئيسية ونص الترحيب، وانتقل جدول الحصص، وفتح نموذج إضافة حصة، وأضيفت حصة جديدة فعلًا.
- انتقل استوديو الحصة وتم تغيير نص السؤال، وعرضت صفحة البروجكتر محتوى مستقلًا.
- دخلت معاينة الطالبة، وفتحت التحدي، وظهرت ثلاثة خيارات للإجابة.
- لم تسجَّل أخطاء JavaScript في الاختبار أعلاه.
- أخذت صور معاينة `preview-teacher.png` و`preview-student.png` و`preview-projector.png`.

## قيود التحقق

لم نُجرِ مراجعة أمنية مستقلة، ولا اختبارًا شاملًا لكل صفحة وكل زر، ولا ضغطًا متعدد المستخدمين أو رفع وسائط حقيقيًا، ولا اختبارات على أجهزة فعلية أو تطبيقات المتاجر. تشغيل JavaScript ضمن الصفحة يثبت صلاحية نموذج الواجهة ولا يثبت جاهزية المشروع إنتاجيًا.

## فحوص قبل أي نشر

- فحص قبول الصلاحيات لكل دور عبر API وليس إخفاء الأزرار.
- فحص عمق المحتوى وتوافق الرياضيات والكسور والتحقق من المرفقات.
- اختبارات Safari iOS وChrome Android، العرض على بروجكتر بوضع التوسيع، إعادة الاتصال، منع تسريب شاشة المعلمة.
- حمولة 1000+ مستخدم، شبكة بطيئة، رفع فيديو مقسّم، فشل الاتصال، نسخ احتياطي واستعادة.
- تدقيق معالجة البيانات الشخصية للأطفال وفق المتطلبات والاشتراطات ذات الصلة قبل التشغيل.
