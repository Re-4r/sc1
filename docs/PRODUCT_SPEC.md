# خارطة منصة «مساحة» الكاملة

هذا المستند يجمع جميع المتطلبات التي نوقشت ويُفرق بينها وبين المنفذ فعلاً. **النسخة الحالية معاينة تفاعلية محلية**؛ البنود الواردة هنا متطلبات التطوير للإصدار الإنتاجي، وليست ادعاءً بأنها تعمل الآن.

## 1) الهوية والتجربة

- تصميم هادئ عصري، لا شبكة بطاقات متكررة ولا تدرجات لونية، ألوان باردة، خط PingARLT، وضوح على الماك والجوال والتابلت والشاشات التعليمية.
- واجهة معلمة عملية مع ترحيب واسم وتاريخ هجري/ميلادي وحصة الآن/القادمة وعدّاد لبداية الحصة ثم لنهايتها، شريط زمني وأدوات مختصرة ومهام منسدلة، وتخصيص أقسام الرئيسية من الإعدادات.
- واجهة طالبات منفصلة طفولية ناعمة بألوان هادئة وأشكال هندسية لطيفة وفرح لا يشتت؛ لا تستخدم أي رمز نجمة، وضمن إمكانية إيقاف الأصوات والحركات.
- واجهة أولياء الأمور آمنة وبسيطة، وواجهة إدارة مستقلة.
- جميع اللغات لاحقًا RTL/LTR، إمكانية تكبير الخط والتباين والوصول بلوحة المفاتيح.

## 2) البنية التقنية المطلوبة

- HTML + CSS + JavaScript منظمة؛ التقليل من ملفات المشروع دون جمع منطق الخادم والواجهة بشكل فوضوي.
- واجهة PWA قابلة للتثبيت مع تحديث موثوق، دعم Safari/Chrome/Edge/Firefox على iOS/Android/macOS/Windows.
- API بخادم PHP 8.1+ أو Backend مكافئ، قاعدة بيانات مضبوطة، اختبارات صلاحيات تلقائية، إعدادات ونسخ احتياطية، توثيق واستعادة وإصدارات وترحيل بيانات.
- تخزين وسائط خارجي Object Storage (S3 compatible) مع chunked/resumable uploads، فحص MIME والامتداد والحجم، روابط موقعة قصيرة العمر، تفريغ ثغرات الملفات، CDN للتوزيع، ملفات متاحة للفصل المصرح فقط. لا تخزن الفيديو الكبير داخل localStorage أو جداول DB.
- تسجيل دخول منفصل للمعلمات والطالبات وأولياء الأمور والإدارة، كلمات مرور آمنة، إعادة تعيين محمية، جلسات قصيرة، CSRF/XSS protections، rate limiting، مراجعة سجلات الوصول، ونطاقات الوصول المصرح بها لكل endpoint.

## 3) التنظيم الأكاديمي

مدرسة ← معلمة ← عام دراسي ← فصل/فترة ← صف ← شعبة ← مادة ← وحدة ← درس ← حصة تنفيذ ← نشاط ← محاولة ونتيجة. إضافة وتعديل وأرشفة أي مستوى من دون إفساد تاريخ الدرجات. محتوى الدرس قابل لإعادة الاستخدام بين الشعب مع فصل نتائج التنفيذ والحضور لكل شعبة.

## 4) إدارة المعلمة

- سجلات الطالبات يدويًا وCSV/Excel/JSON مع معاينة وتحذير من التكرارات، النقل/الأرشفة من دون فقد السجل.
- توزيع المقاعد بالسحب، تكوين مجموعات 2–5+، الحضور لكل حصة مع عدم افتراض حضور أحد قبل الرصد، واستبعاد الغائبات من الاختيار العشوائي.
- تقويم وطني/مدرسي قابل للضبط: عام/فصل/بداية ونهاية/أيام دوام/إجازات/اختبارات/مناسبات/جدول حصص/حصص تعويضية، وكلها من الإدارة لا من افتراضات خارجية.
- مهام روتينية تجدد تلقائيًا كل يوم، يومية وأسبوعية، الأولويات والتثبيت والمواعيد والإنجاز والرشاقة في العرض، ومذكرات المعلمة، تنبيهات اختيارية موثوقة مع عدم اعتبار إشعار المتصفح مضمون الوصول.
- أدوات الحصة: مؤقت/ساعة إيقاف، اختيار عشوائي، مجموعات، تعليمات الصف، تهيئة، مراجعة سابقة، أنشطة تعلم نشط وتقييم ختامي وتذكرة خروج، مشاركة ونقاط وفريق السر ومكافآت.
- تحضير الدرس: تمهيد/أهداف/مفاهيم/قوانين/نموذج خطوة بخطوة/تدريب موجه ومستقل/سؤال تكويني/تذكرة خروج/واجب/إثراء/علاج/توثيق أدلة التنفيذ.
- واجبات صفية ومنزلية وتدريبات إضافية منفصلة عن درجات التقييم، بنك أسئلة مهاري بالصفحة المرجعية، محاولات مرنة وتحقق من التعادل الرياضي للكسور، قوالب اختبارات ومراجعة قبل النشر.
- تقارير فردية وجماعية، مستويات مهارة وعلاج، تصدير PDF وCSV، شهادات مصممة للمجموعات والفصول، ملف إنجاز المعلمة، استراتيجيات وإثباتات ومراجعة بشرية قبل تحويل النشاط إلى «منجز».

## 5) البروجكتر وشاشتان منفصلتان

- استوديو الإدارة يعمل على جهاز المعلمة مستقلًا؛ `projector.html` فقط للسبورة، لا يظهر تسجيل دخول ولا إعدادات ولا بيانات حساسة.
- للعمل على شاشة بروجكتر واحدة مع اللابتوب يجب استخدام وضع توسيع الشاشة. تعتيم فوري، تهيئة الشريحة التالية دون كشفها، إظهار حل تدريجي، أدوات إيضاح، مؤقت، صوت باختيار المعلمة.
- المزامنة الحالية تنجح فقط بين نوافذ نفس الأصل في المتصفح؛ الإنتاج يتطلب جلسة مؤقتة قصيرة الرموز وتزامن WebSocket/SSE مع مصادقة للمعلمة وواجهة عرض عامة بدون أسرار.
- دعم تعليم الكسور بمقام وبسط وخط أفقي، مع الحفاظ على ترتيب تسلسل الدرس المنهجي.

## 6) الطالبة

لوحة مهام مرتبطة بالشعبة والصف، الكتاب والدفتر والحاسبة وملخص قوانين، دروس PDF/PowerPoint/فيديو مرخّص، أسئلة وتدريبات، تصحيح خطوة بخطوة، خيار «ما فهمت» مع تفكيك المفهوم تدريجيًا ونماذج بديلة وتحليل المهارات السابقة، حالات إنجاز وتحفيز ومنح شهادات، مسابقات عملية تعلم وليست مجرد تزيين. فصل بيانات حساب الطالبة عن حساب ولي أمرها.

## 7) الألعاب

شد الحبل للفريقين، عبور الجسر، تحديات الضرب، متاهة الرياضيات، الذاكرة، البنغو، صندوق الكنز، متجر الرياضيات، تركيب المربعات، المفتاح والقفل، اكتشاف الخطأ، خط الأعداد، مختبر الكسور، القياس والهندسة. كل لعبة مرتبطة بمهارة وسجل نتائج يمكن إيقاف التحفيز الصوتي/البصري فيها. **المتاح الآن فقط مسابقة نقاط فريقين وتحدي حساب مختصر ونموذج هدية تشجيعية**.

## 8) ولي الأمر

حساب مستقل ونموذج ربط بطالبة واحدة أو أكثر بعد تحقق وموافقة مناسبة، دعوة QR مؤقتة أحادية الاستخدام، خيارات مستقلة لكل شعبة: مراجعة المعلمة، تلقائي بعد تحقق موثوق، فريق العمل فقط، مغلق. دون مزود تحقق لا يُستنتج امتلاك رقم الجوال من إدخاله. يرى فقط الأبناء المرتبطين وحضورهم ومستوياتهم وواجباتهم وشهاداتهم المصرح بنشرها. رابط واتساب رسمي اختيارب لكل طالبة من المعلمة، ولا يُعتبر فتح الرابط دليل وصول.

## 9) الإدارة والصلاحيات

إدارة أعضاء الفريق وصلاحيات تفصيلية: عمومي ثم صف ثم شعبة ثم نشاط ثم استثناء طالبة، سجل تدقيق، مراجعة تغييرات الدرجات، نسخ احتياطية وحذف منضبط للبيانات، تقييد النشر، مراجعة ملفات المستخدمين، تنبيهات الصلاحيات، مساحة تخزين وحصص استخدام.

## 10) الذكاء المساعد

استوديو برومبتات منظمة محفوظة بحسب المادة والصف والدرس مع زر «نسخ» وفتح ChatGPT/Gemini/Claude دون زعم الإرسال التلقائي إلى مواقع أخرى. إنتاج JSON للأهداف والأسئلة، استيراد مع مراجعة بشرية للرياضيات والصفحات قبل النشر. تكامل API اختياري ومقيد بمحتوى منهج معتمد؛ عدم إرسال بيانات طالبة خاصة دون أساس قانوني.

## 11) أولويات التنفيذ الإنتاجي

1. قاعدة البيانات وهوية المستخدمين وصلاحيات الاطلاع والتحقق من ولي الأمر، والاختبارات الأمنية.
2. السنة الدراسية والصفوف والطالبات والجدول والتحضير والحضور ودورات المحتوى.
3. خدمة الوسائط كبيرة الحجم والمراجعة والنشر والصلاحيات والتخزين المؤقت.
4. واجهة السبورة الحية ذات جلستين وأجهزة متعددة والتحكم عن بعد.
5. الواجبات ومحرك الرياضيات الصحيح والدرجات والحماية من التلاعب وسجلات المحاولات.
6. بوابة الطالبات والأهل الموثقة، التقارير والشهادات والتواصل.
7. الألعاب الموسعة والتقارير العلاجية والاستوديو المساعد والتوسع المدرسي.

## 12) معيار القبول

أي ميزة لا تُعد «مكتملة» حتى تحقق: حفظًا على الخادم، اختبار صلاحيات فعلي، صحة البيانات، اختبارًا على الجوال وSafari، حالات الخطأ والاستعادة، توثيقًا، معاينة على شاشة المعلمة والبروجكتر إذا لزم. يمنع وصف نموذج محلي بأنه منصة مدرسية جاهزة.
